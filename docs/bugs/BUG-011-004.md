## Descrição

O hostname enviado pelo cliente no campo `Message::Hello { hostname }` não tinha limite de tamanho. Um cliente malicioso podia enviar um hostname com megabytes de texto, que seria usado em notificações do sistema (`send_notification`), strings de log e na UI — potencialmente causando problemas de memória ou UI.

---

## Passos para reproduzir

1. Servidor Movex em execução
2. Cliente malicioso envia `Hello { hostname: "A".repeat(10_000_000) }`
3. Servidor aceita, hostname é usado em notificação do sistema e persistido em `recent_peers`

---

## Comportamento esperado

Hostname deve ser truncado a um comprimento razoável antes de uso.

---

## Causa raiz

`server.rs:185-196` — hostname aceite sem validação de tamanho.

---

## Correção aplicada

`src-tauri/src/core/server.rs`:
- Hostname truncado a 64 caracteres Unicode: `.trim().chars().take(64).collect::<String>()`
- Hostname vazio após trim rejeitado com `HelloReject`
